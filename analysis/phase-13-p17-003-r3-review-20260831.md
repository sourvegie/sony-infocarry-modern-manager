## Independent correction loop

The first independent R3 review failed closed on four findings:

1. The bridge accepted an altered supplied native template because the generic
   builder checked structure and prefix length but not reviewed template
   identity.
2. Authorization checked the Library binding embedded in the candidate audit
   but not the candidate wrapper's top-level binding.
3. A catalog package item could disagree with the current manifest's source
   identity and observed manifest metadata.
4. The preflight audit mapping exposed mutable nested report state outside the
   seal inputs.

The correction adds the exact reviewed native template blob hash gate,
top-level/nested binding checks, canonical catalog source/manifest/observation
checks, and recursive report freezing with a detached JSON-friendly view.
Focused tests now cover each finding. The correction did not alter P16 raw
evidence or broaden package semantics.

The independent re-review found no remaining code-safety findings. It reported
two documentation-only blockers, both corrected before this final record: the
risk register's stale test count and this previously absent durable R3 review
record.
